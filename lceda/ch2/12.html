2.12 制造文件

画完板子要交给工厂的，不是 EDA 工程本身，而是几份“标准格式”的制造文件：Gerber、钻孔文件、BOM、坐标文件。这一节讲清楚每份文件是什么、谁用它、什么时候需要它，以及钢网是什么。

⏱ 约 15 分钟🎯 零基础📦 附案例 A 的真实导出文件

一张表看懂：做什么需要什么文件#

文件是什么（大白话）谁用只做光板还要 SMT 贴片
Gerber（压缩包）每一层的“底片”：铜、阻焊、丝印、板框……PCB 工厂✅ 必须✅ 必须
钻孔文件 .DRL在哪儿打多大的孔（已包含在 Gerber 压缩包里）PCB 工厂的钻床✅ 必须✅ 必须
BOM 物料清单用了哪些元件、每种几个、型号和编号采购 / SMT 工厂—✅ 必须
坐标文件 CPL每个元件的中心坐标、旋转角度、在哪一面贴片机—✅ 必须
钢网（实物）刷锡膏用的镂空钢片，按锡膏层做SMT 工厂 / 自己刷锡膏—工厂自己做

在嘉立创EDA 里，这些都在顶部菜单「导出」里（A-10.1）。用“一键下单”时，编辑器会自动把 Gerber、BOM、坐标文件一起生成并上传，不用手动传文件。

Gerber：每一层的“底片”#

Gerber 是 PCB 行业通用的文件格式（现在主流的是 RS-274X 扩展格式），每个文件描述一层的图形——就像印刷厂拿到每种颜色的印版。任何 PCB 工厂都认 Gerber，所以导出的压缩包也可以发给别的工厂。

案例 A 导出的 Gerber 压缩包里有这些文件（扩展名大多是行业习惯的缩写：G = Gerber，T / B = Top / Bottom，L = Layer，O = Overlay 丝印，S = Solder mask 阻焊，P = Paste 锡膏）：

文件内容生产时用在
Gerber_TopLayer.GTL / Gerber_BottomLayer.GBL顶层 / 底层铜图形转移、蚀刻
Gerber_TopSolderMaskLayer.GTS / …Bottom….GBS顶层 / 底层阻焊开窗阻焊
Gerber_TopSilkscreenLayer.GTO / …Bottom….GBO顶层 / 底层丝印丝印
Gerber_TopPasteMaskLayer.GTP顶层锡膏（钢网开孔）做钢网
Gerber_BoardOutlineLayer.GKO板框成型
Drill_PTH_Through.DRL / Drill_PTH_Through_Via.DRL钻孔数据（元件孔 / 过孔），PTH 表示孔壁要镀铜钻孔
Gerber_DrillDrawingLayer.GDD钻孔图（给人看的孔位示意）参考
FlyingProbeTesting.json飞针测试数据电测
其他（文档层、机械层、下单必读）说明性内容参考

完整说明见 A-10 压缩包里有什么，每一步怎么用见 2.11 工艺流程。

Gerber 是“所见即所得”的：工厂只按 Gerber 做，不会去看你的原理图。所以导出前一定要跑一遍 DRC，有条件的话用 Gerber 预览（下单页的仿真图里有「Gerber图形」）看一眼——丝印有没有压在焊盘上、板框是不是闭合的。

BOM：元件清单#

BOM（Bill of Materials）是一张表格，列出板子上用到的所有元件。案例 A 导出的 BOM 里几行长这样（节选）：

QuantityCommentDesignatorFootprintManufacturer PartSupplier Part
110uFC1C0805CL21A106KAYNNNEC15850
4330ΩR5,R6,R7,R8R06030603WAF3300T5EC23138
2KT-0603WLED1,LED2LED0603-R-RD_WHITEKT-0603WC2290
1NE555DRU1SOIC-8_L4.9-W3.9-P1.27-LS6.0-BLNE555DRC7593

（真实文件还有 No.、Value、Manufacturer、Supplier 几列。封装名里藏着尺寸：L4.9-W3.9 是本体长宽，P1.27 是脚距，LS6.0 是含引脚的总宽——和 2.5 里的数字对得上。）

  • Designator（位号）告诉工厂这种料贴在哪几个位置；Supplier Part（供应商编号，即立创商城 C 编号）告诉工厂用哪一种料。
  • BOM 里“加入 BOM = 否”的元件不会出现（案例 B 的排针 J1 就设成了否，因为打算自己焊）。
  • 导出前编辑器会提示“器件标准化”，作用是检查每个元件的属性和立创编号是否一致，避免工厂配错料。

坐标文件：贴片机的“地图”#

坐标文件（CPL / Pick and Place）记录每个贴片元件的位号、中心坐标、旋转角度、在顶层还是底层。贴片机按它把元件一个个放到正确位置、转到正确方向。

案例 A 导出的坐标文件里，U1 那一行是这样的（节选）：

DesignatorFootprintMid XMid YPad XPad YLayerRotation
U1SOIC-8_L4.9-W3.9-P1.27-LS6.0-BL20mm-19mm18.095mm-21.6mmT0

意思是：U1 的中心在 (20, −19) mm，在顶层（T），旋转 0°；1 号焊盘在 (18.095, −21.6) mm。这正是 A-5 参考布局里给 U1 定的位置。

方向最容易出问题。不同库里同一个元件的“0°”定义可能不一样，所以 SMT 下单后工厂会给出贴片预览让你确认。重点检查有方向的元件：芯片的 1 脚、LED 和二极管的正负极、电解电容、模组。

钢网：给焊盘刷锡膏的镂空模板#

机器贴片前，要先在每个贴片焊盘上涂一层锡膏（锡粉 + 助焊剂调成的膏）。做法是把一张薄薄的钢网盖在板子上，钢网上对应焊盘的位置开了孔，用刮刀一刮，锡膏就从孔里漏到焊盘上——就像用镂空模板刷油漆。

  • 钢网的开孔形状来自锡膏层（Gerber 包里的 …PasteMaskLayer.GTP），封装自带，一般不用自己画。
  • 用嘉立创 SMT 贴片时，钢网由工厂负责；自己手工用锡膏 + 热风枪 / 加热台焊接时，可以单独下单买“激光钢网”（下单页有这个选项）。

📦 案例 A 导出的真实文件，可以下载打开看看： Gerber 压缩包 BOM 表 坐标文件

只想让工厂做 5 块空白电路板（不贴元件），最少要提供什么？
✅ 光板只需要 Gerber（里面已包含钻孔文件）。BOM 和坐标文件是贴片才需要的。
贴片机靠哪个文件知道每个元件放在哪、转多少度？
✅ 坐标文件记录了位置和角度；BOM 记录用什么料。两者配合，贴片机才知道“在哪儿放什么”。

2.6 怎么读原理图

原理图是电路的“地图”：它不管元件实际多大、放在哪，只回答一个问题——谁和谁连在一起。学会看符号、位号、网络和几个特殊标记，别人的原理图你也能看懂。

⏱ 约 20 分钟🎯 零基础🖱️ 含“找连接”小练习

常用符号速查#

符号是什么位号字母详见
电阻（国标长方形；美标画成锯齿）R2.4
电容（无极性）C2.4
有极性电容（电解 / 钽），标 + 的一端是正极C2.4
电感L2.4
二极管：三角形指向电流方向，竖线一侧是负极D2.4
LED：二极管 + 向外的两个小箭头（发光）LED / D2.4
NPN 三极管Q2.4
晶振Y / X2.4
按键SW / K2.4
芯片：一个方框加一圈引脚，每只脚标编号和名字U2.14
连接器 / 排针J / P / USB2.4
电源符号（名字可以是 VCC、3V3、VBUS……）—2.2
地 GND—2.2
网络标签：给导线起名字，同名即相连—下文
连接点：实心圆点，表示这几根线真的连在一起—下文
两根线交叉但没有圆点：不相连，只是跨过去—下文
非连接标识（红叉）：这只脚故意不接—下文

位号：R1、C3、U1 是什么意思#

每个元件都有一个唯一的位号（Designator）：字母表示元件种类，数字区分同类的第几个。R5 就是“第 5 个电阻”。位号会印在 PCB 丝印上，焊接、调试、看 BOM 都靠它找元件。

字母元件案例里的例子
R电阻R1～R8（案例 A）
C电容C1～C3（A）、C1～C9（B）
L电感—
D / LED二极管 / 发光二极管D1（B）、LED1～LED4（A）
Q三极管、MOS 管—
U芯片、模组U1 NE555（A）；U1 ESP32-C3 模组、U2 AMS1117（B）
J / P / CN / USB连接器、排针、插座USB1（A、B）、J1 排针（B）
SW / K开关、按键SW1 RESET、SW2 BOOT（B）
Y / X晶振—
F / TP保险丝 / 测试点—

字母习惯不是死规定，不同公司、不同软件略有差别（比如 LED 有人用 D，有人用 LED）。嘉立创EDA 放置元件时会按库里的前缀自动编号，也可以用「分配位号」重新整理（A-2.12）。

引脚：编号和名字#

芯片符号的每只引脚有两个标识：

  • 引脚编号（1、2、3……）：对应封装上的焊盘编号，原理图转 PCB 时就是靠编号把“符号的脚”和“封装的焊盘”对上的。
  • 引脚名（VCC、GND、OUT、TRIG……）：告诉你这只脚是干什么的。

例如 NE555 的 3 脚叫 OUT，8 脚叫 VCC。原理图上引脚的排列位置不代表真实位置——符号是为了画图方便重新排过的，真实位置看规格书的引脚图（2.14）。

网络：判断“谁和谁连在一起”#

原理图最核心的信息就是网络（Net）：连在一起的所有引脚组成一个网络，网络里各处电压相同。判断两个引脚是否在同一个网络，看这几种情况：

  1. 有导线直接连着（中间可以拐弯）→ 相连。
  2. 导线丁字或十字交汇，交汇处有实心圆点（连接点）→ 相连。
  3. 两根线交叉、交叉处没有圆点 → 不相连，只是画的时候跨过去。
  4. 名字相同的电源符号（VCC、GND……）→ 相连，哪怕图上离得很远。
  5. 名字相同的网络标签（比如两处都写着 OUT）→ 相连。
  6. 同一个元件的两端（比如电阻的两只脚）→ 不是同一个网络，中间隔着元件。

注意 R7 上方的竖线和 U1 第 5 脚的横线交叉的地方：没有圆点。还有两个写着 OUT 的网络标签。

网络标签有什么好处？ 一张复杂的原理图，如果所有连接都用导线画，会像一盘意大利面。给导线起个名字（网络标签），在需要的地方再放一个同名标签，就“隔空”连上了，图面清清楚楚。案例 B 就大量使用了 USB_D+、RGB_DIN、EN 这样的网络标签，并且按功能分块（电源、USB、MCU、RGB 灯）来画。

转到 PCB 后，同一网络的焊盘之间会出现飞线，提示你“这些要连起来”（A-3）。

非连接标识：这只脚故意不接#

芯片上不用的引脚，可以放一个非连接标识（红色小叉），告诉检查工具“这只脚是故意空着的，不是忘了接”。案例 B 的 USB 插座 SBU1、SBU2 和模组上没用的 IO 都打了叉，原理图 DRC 的“引脚悬空”警告就消失了（A-2.10）。

不是所有不用的引脚都能空着！有些芯片要求某些脚必须接高或接低（比如 NE555 的 4 脚 RESET 不用时要接 VCC，否则芯片可能被复位而不工作；ESP32-C3 的几个启动相关引脚也有要求）。拿不准就看规格书。

拿到一张陌生原理图，怎么读#

  1. 先找电源：电从哪里进来（USB、电池），经过什么变成了哪几种电压（5 V → 3.3 V）。
  2. 再找主角：最大的那颗芯片（U1）是什么型号，查一下它是干什么的。
  3. 看输入和输出：按键、传感器是输入；LED、电机、屏幕是输出；它们分别接在主芯片的哪只脚上。
  4. 最后看配角：芯片旁边的小电阻、小电容多半是去耦、上拉、限流这些“标配”，看懂 2.3、2.4、2.7 就能认出来。

✅ 没有连接点圆点 = 不相连。为了避免误会，好的画图习惯是尽量用“丁字”连接，少画十字交叉的连接。

✅ 同名网络标签自动相连。反过来，如果不小心把名字打错（比如 RGB_DlN），它们就不相连了——这是常见的低级错误。

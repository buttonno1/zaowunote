2.13 SMT 与手工焊接

光板拿到手只是一块“空地”，元件要焊上去才能用。两条路：交给工厂用机器贴片（SMT），或者自己拿电烙铁焊。这一节讲清楚两条路各怎么走，以及好焊点和坏焊点长什么样。

⏱ 约 20 分钟🎯 零基础🖼️ 含好焊点 / 坏焊点对比图

路线 ①：工厂 SMT 贴片#

SMT（Surface Mount Technology，表面贴装技术）是工厂用机器焊贴片元件的流程，主要四步：

  1. 印锡膏：用钢网往每个焊盘上刷一层锡膏（2.12 钢网）。
  2. 贴片：贴片机按坐标文件用吸嘴吸起元件，转到规定角度，放到焊盘上（锡膏有黏性，能暂时粘住）。
  3. 回流焊：板子过一个温度分段控制的长炉子，锡膏熔化再冷却，元件就焊牢了。
  4. 检查：用 AOI（自动光学检测）等方式检查有没有偏位、漏件、连锡。有直插元件的还要再插件焊接。

在嘉立创下 SMT 订单的大致流程#

  1. 先下 PCB 订单（A-10），下单页「SMT 贴片」一项选“需要”。
  2. 等 PCB 订单审核通过后，在 SMT 下单页面上传 BOM + 坐标文件（也可以从编辑器的「导出 → 嘉立创SMT备料下单…」进入）。
  3. 核对元件匹配结果：每个元件对应到了哪个立创编号、有没有缺货、哪些是扩展库。
  4. 核对贴片方向预览：芯片 1 脚、LED 和二极管极性、模组方向，最重要。
  5. 确认费用并支付，等板子贴好寄过来。

以上流程按 2026-11 下单页面上的说明整理；本教程没有实际提交 SMT 订单，具体界面以嘉立创网站为准。

基础库和扩展库：嘉立创 SMT 把元件分成两类。基础库是贴片机上常备的常用料（普通电阻电容、常见 LED……），直接用；扩展库是需要临时装到机器上的料，通常要多收一笔换料费。所以选元件时能用基础库就用基础库——在嘉立创EDA 搜索元件时，立创商城来源的列表里可以看到每个元件属于哪一类（A-0 元件清单）。案例 A 只有 NE555 和 Type-C 座是扩展库。

路线 ②：自己手工焊接#

工具清单#

工具用途 / 选购建议
恒温电烙铁能调温度的那种。尖头适合小元件，刀头适合拖焊芯片
焊锡丝0.5～0.8 mm 粗，内含助焊剂。有铅焊锡（如 63/37，熔点约 183 °C）更好焊；无铅焊锡熔点更高、稍难焊
助焊剂帮焊锡流动、去氧化。焊贴片、修连锡时非常有用
尖头镊子夹贴片元件，必备
吸锡带吸掉多余的焊锡、修连锡
放大镜 / 手机微距检查 0603、芯片引脚的焊点
万用表（选购）测通断、测电压，排查短路
热风枪 / 加热台（选购）焊 QFN、拆芯片、配合锡膏焊

安全第一：

  • 烙铁头有好几百度，不用时放回烙铁架，别放桌上；电源线别从烙铁头旁边绕过。
  • 焊接产生的烟主要是助焊剂挥发，保持通风，别凑太近吸。
  • 用有铅焊锡后洗手再吃东西。
  • 剪引脚时线头会弹飞，注意眼睛。
  • 焊接时板子不要通电。

焊直插元件：五步法#

  1. 准备：元件插好，板子固定住。烙铁温度一般 300～350 °C 左右（按焊锡说明调）。
  2. 加热：烙铁头同时贴住焊盘和引脚，约 1～2 秒。
  3. 送锡：把焊锡丝送到焊盘和引脚的交界处（不是送到烙铁头上），看到焊锡熔化、铺开。
  4. 移开焊锡丝：锡量够了先拿开焊锡丝。
  5. 移开烙铁：再顺着引脚方向拿开烙铁。焊点冷却前别晃动。整个过程 2～4 秒。

焊贴片电阻电容（0603 / 0805 / 1206）#

  1. 先给一个焊盘上一点锡。
  2. 镊子夹住元件，烙铁熔化这点锡，把元件推到位，移开烙铁——一端就固定住了。
  3. 焊另一端（正常送锡）。
  4. 回头给第一端补一点锡，让两端都形成小斜坡。

焊 SOIC 芯片（比如 NE555）#

  1. 确认 1 脚方向：芯片上的圆点对准丝印上的 1 脚标记。
  2. 给一个角的焊盘上锡，镊子把芯片对准所有焊盘，焊住这一只脚固定。
  3. 检查另一侧也对齐了，再焊对角的脚。
  4. 逐个焊其余引脚；或者涂助焊剂后用刀头“拖焊”一排。
  5. 放大检查有没有连锡，有的话加助焊剂用烙铁拖开或用吸锡带吸掉。

焊接顺序：先矮后高、先小后大、先难后易。先焊芯片和小贴片，再焊连接器、排针这些高的元件，否则高元件会挡住烙铁。案例 A 的完整手焊顺序见 A-11.2。

好焊点与坏焊点#

好焊点 / 坏焊点对比图
侧视示意图（灰色是焊锡，橙色是焊盘，深灰竖条是引脚）。实际焊点很小，记得用放大镜检查。

焊完先别急着通电#

  • 放大检查每个焊点：没有连锡、没有虚焊、没有漏焊
  • 有极性的元件（LED、二极管、电解电容、芯片 1 脚）方向都对
  • 用万用表通断档测一下电源和 GND 之间没有短路（不响才对）
  • 第一次上电时手放在电源旁边，闻到焦味、看到冒烟立刻拔掉
手焊直插元件时，焊锡丝应该送到哪里？
✅ 焊盘和引脚都被加热后，焊锡碰到它们自然熔化铺开，才能焊牢。把锡先熔在烙铁头上再抹，助焊剂早就烧没了，容易冷焊。
用嘉立创 SMT，为什么尽量选“基础库”的元件？
✅ 扩展库也能贴，只是需要临时上料，通常多收费。

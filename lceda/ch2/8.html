2.8 单片机入门

单片机是一颗“装在芯片里的小电脑”。这一节讲它由什么组成、GPIO 引脚怎么控制外面的东西、程序是怎么“写进去”的，以及串口和 USB——都是为案例 B 的 ESP32-C3 彩灯板做准备。

⏱ 约 15 分钟🎯 需要 2.7 的基础

单片机 = 一颗芯片里的小电脑#

单片机（MCU，Microcontroller Unit）把一台电脑最基本的部分都塞进了一颗芯片：

和电脑相比，单片机很“弱”（ESP32-C3 主频最高 160 MHz，内存几百 KB），但它便宜、省电、上电就跑，非常适合控制灯、电机、传感器这类事情。洗衣机、电饭煲、遥控器里都有单片机。

芯片和模组：案例 B 用的 ESP32-C3-MINI-1 是一个模组：乐鑫把 ESP32-C3 芯片、4 MB Flash、晶振、PCB 天线和外围元件做在一块邮票大小的小板上，还加了金属屏蔽罩。我们只要把整个模组焊到自己的板子上、接好电源和几个按键就能用，不用操心射频电路——这对新手非常友好。

GPIO：程序控制的引脚#

GPIO（通用输入输出）是单片机上可以由程序控制的引脚，每只都有编号（ESP32-C3 叫 IO0、IO1……）：

  • 输出模式：程序让它输出高电平（3.3 V）或低电平（0 V），去点亮 LED、控制别的芯片。比如 digitalWrite(8, HIGH)。
  • 输入模式：程序读取外面接进来的是高还是低，比如检测按键有没有按下（记得上拉电阻，2.7）。
  • 很多 GPIO 还有“兼职”：模拟输入（测电压）、PWM（调光）、串口、I²C、SPI 等。

GPIO 的输出能力很有限：只能直接带 LED 这种小电流负载。电机、继电器、大功率灯要通过三极管 / MOS 管去控制（2.4）。另外有些 GPIO 在上电时有特殊用途（启动配置脚，ESP32-C3 的 IO2、IO8、IO9），连外部电路前要查规格书。

案例 B 里，IO8 接到第一颗 RGB 灯的数据输入（网络 RGB_DIN），三颗灯首尾串成一串：前一颗的 DOUT 接后一颗的 DIN。程序从 IO8 发出一串数据，就能分别设置每颗灯的颜色。

程序是怎么“写进去”的：烧录#

你在电脑上写的程序，要变成单片机能执行的机器码，再存进它的 Flash 里，这个过程叫烧录（也叫下载、上传、Flash）。以 Arduino 为例：

  1. 在电脑上用 Arduino IDE 写程序（C/C++ 语言）。
  2. 点「上传」：软件先把程序编译成机器码。
  3. 通过 USB 线把机器码发给单片机，单片机里自带的“引导程序”把它写进 Flash。
  4. 写完后单片机自动重启，开始运行你的程序。以后每次上电都会自动运行，不用再连电脑。

RESET 和 BOOT 两个按键是干什么的？

  • RESET（复位）：让芯片重启，相当于电脑的重启键。
  • BOOT（启动模式）：ESP32-C3 重启时会看 IO9 的电平决定做什么——IO9 为高（平时，内部上拉）就正常运行程序；按住 BOOT（IO9 为低）再按一下 RESET，就进入“等待下载”模式。
  • 大多数情况下通过 USB 上传是自动的，不用按键。如果上传失败、或者程序写坏了导致 USB 连不上，就用“按住 BOOT → 按一下 RESET → 松开 BOOT”这个组合强制进入下载模式，再上传一次。

串口和 USB#

  • 串口（UART）：最简单、最常用的通信方式，只要两根信号线：TX（发）和 RX（收），外加 GND。两个设备连接时要交叉：A 的 TX 接 B 的 RX，A 的 RX 接 B 的 TX。单片机常用串口把调试信息“打印”到电脑上（Arduino 的 Serial.println()），这是排查程序问题的头号工具。
  • USB：电脑和单片机之间更方便的连接方式。很多老单片机自己不会“说 USB”，板子上要额外放一颗 USB 转串口芯片；ESP32-C3 芯片内置了 USB 串口 / 调试功能，USB 的 D− / D+ 直接接到模组的 IO18 / IO19 就行，省掉了一颗芯片。这就是案例 B 的 USB_D− / USB_D+ 网络。

USB 的 D+ / D− 是一对差分信号，PCB 上要两根并排、等长地走（差分对布线）。案例 B 的 PCB 设计会演示怎么做。

单片机的程序存在哪里，断电后还在吗？
✅ 程序烧录进 Flash，断电不丢，上电自动运行。RAM 只是运行时临时存数据用的。
两块板子用串口通信，接线正确的是？
✅ 一方的“发”要接另一方的“收”。别忘了 GND——共地。

# 造物笔记 · zaowunote

一个面向新手的手工 / 硬件教程站。每本教程都从“完全没碰过这个软件”讲起，
先跟着做完一个真实的小作品，再回头补原理和细节。

制作图文教程的初衷是为了可以快速上手一个新领域，快速了解一个新的技能或者软件。因为我在学习这些软件的时候，看视频觉得太长了，想要翻某一节又不方便翻

**本教程网站由ai辅助制作**

ai的参与给网页制作了很多可以互动的环节，ai的加入也意味着网站的修改很方便，如果你在阅读教程中看到需要改进的地方可以提issue

目前之后纯静态网站，后期更新的差不多了会抽出时间来改造

## 怎么读

每本教程都是同一个结构，按顺序走就行：

| 阶段 | 章节 | 干什么 |
|---|---|---|
| ① 准备 | **第 0 章 · 开始之前** | 要装什么、这软件到底能做什么、快捷键怎么按 |
| ② 上手 | **第 1 章 · Quickstart** | 跟着做完一个完整作品，先做出来，再理解 |
| ③ 补全 | **第 2 章 · 基础知识** | 把 Quickstart 里含糊带过的概念讲清楚 |
| ④ 查手册 | **第 3 章起** | 按功能分章，遇到问题像查工具书一样翻 |


## 现在有什么



| 教程 | 你会做出什么 | 进度 |
|---|---|---|
| 嘉立创EDA 专业版 | 从不懂电路，到设计出一块能真实下单生产的电路板 | 第 0～7 章，59 节 |
| Autodesk Fusion（原 Fusion 360） | 从没碰过 3D 软件，到做出能 3D 打印、能装配的小东西 | 第 0～8 章，73 节 |

- **嘉立创EDA** 的 Quickstart 有两个完整案例：眨眼小徽章、ESP32-C3 彩灯板。
  从画原理图、画 PCB，一直到导出 Gerber、BOM 去下单。
- **Fusion（原 Fusion 360）** 的 Quickstart 是一个可折叠、能调角度的手机支架：草图 → 实体 → 圆角 →
  螺纹 → 联接 → 导出 STL，一条线走完。

目前只有立创eda，和fusion360的教程，并且还在更新着，计划以后会更新

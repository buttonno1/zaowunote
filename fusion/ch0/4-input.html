0.4 鼠标、触控板与快捷键

三维软件的操作非常依赖鼠标：旋转视角、平移、缩放每分钟都要做几十次。这一页讲鼠标、触控板怎么用，以及常用的快捷键。

⏱ 约 8 分钟

强烈推荐：三键鼠标#

三键鼠标就是带滚轮的普通鼠标（滚轮可以按下去，算“中键”）。Fusion 默认的操作：

动作鼠标
选择左键单击；⇧ + 左键加选
框选左键在空白处拖：从左往右 = 完全框住才选；从右往左 = 碰到就选
缩放滚动滚轮
平移按住中键拖
旋转视角⇧ + 按住中键拖
适合窗口双击中键
快捷菜单右键（圆盘菜单 + 列表）

如果你以前用过 SolidWorks、Inventor 等软件，可以在「首选项 → 常规 → 鼠标设置（平移、缩放和动态观察）」里换成它们的操作习惯。本教程按默认的「Fusion」写。

只有触控板怎么办#

  • 可以用，但不如鼠标顺手，建议尽早配一个鼠标。
  • 「首选项 → 常规」里勾选「使用基于手势视图导航」后，可以用双指手势平移、捏合缩放、配合按键旋转视角。具体手势以你电脑上的实际效果为准。
  • 不用手势也能操作：点画布下方导航栏的「动态观察」「平移」按钮，再用单指拖动；或者直接点 ViewCube 的面和角切换视角。

Mac 和 Windows 的区别#

  • 本教程的快捷键按 Mac 写；右上角切换到 Windows 后，⌘ 会自动显示成 Ctrl，⌥ 显示成 Alt。
  • Fusion 的单字母快捷键（E、D、L……）两个系统一样。
  • 输入法：单字母快捷键只在英文输入状态下有效。中文输入法下按 E 会打出候选字。命令输入框里要输入中文（比如刻字），切换中文后记得切回来。

常用快捷键#

快捷键命令快捷键命令
S搜索命令（工具箱）E拉伸
L直线R矩形
C圆D草图尺寸
H孔⌘Z撤销（重做用左上角应用栏的 ↷ 按钮）
⌘S保存esc结束当前命令 / 取消选择
delete删除选中的东西return确认对话框（相当于点「确定」）

更多快捷键：菜单里命令名后面的字母就是它的快捷键；按 S 搜索时也会显示。全部快捷键见附录。

记不住快捷键没关系，Quickstart 里每一步都写了在工具栏哪里点。用熟了再换快捷键。
